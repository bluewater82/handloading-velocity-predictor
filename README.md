# Handloading Muzzle Velocity Predictor

Personal machine learning project to predict firearm muzzle velocities using features like cartridge, powder charge, bullet weight, barrel length, etc.

Data ethically sourced from public sources (e.g., r/reloading chrono threads via Reddit API).

Uses scikit-learn/XGBoost for regression models.

In progress: Dataset compilation, feature engineering, model training, Streamlit deployment planned.

Non-commercial, educational use only.
